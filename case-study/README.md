# FMCG Sales Analysis — Top-N & Period Comparison

*Power BI · DAX (what-if parameters) · shareable (public case-study data)*

A fast-moving-consumer-goods sales analysis structured as a set of answered business questions.

## Highlights
- **What-if parameters** driving dynamic Top-N / Bottom-N ranking
- Month-over-month comparison periods
- Dedicated **tooltip pages** for drill context
- Waterfall, stacked-area, and decomposition-style breakdowns
